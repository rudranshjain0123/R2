# SmartestBot

SmartestBot is a custom Slack bot built for Hack Club Stardance.

## Commands

* `/smartestbot-ping` — Check bot latency
* `/smartestbot-help` — Show all available commands
* `/smartestbot-calc 25 * 4` — Multiply two numbers

## Technology

* Node.js
* JavaScript
* Slack Bolt
* Slack Socket Mode
* Hack Club Nest

## Deployment

SmartestBot is deployed on Hack Club Nest and runs continuously using a systemd service.

## AI Usage

AI was used as a coding assistant for troubleshooting, explaining commands, and writing or modifying parts of the code. The project direction, creative decisions, Slack configuration, testing, and deployment were handled by the project creator.
